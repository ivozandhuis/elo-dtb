# PiCo &harr; Wikidata crosswalk

Term-by-term comparison of the PiCo RDF model against Wikidata, done for the hack-a-lod (NDE) challenge. See [crosswalk.md](crosswalk.md). Please note that *underlying models are not compatible* (e.g. PiCO source, person observation to person reconstruction, with Wikidata -all in one- approach).

Vocabulary-level only (which Wikidata property/item, if any, matches a given PiCo class/property) — not an instance-level crosswalk of actual Leiden persons, which a quick check showed isn't viable for this kind of ordinary-person genealogical data (see the ["Takeaways" section](crosswalk.md#takeaways) in the crosswalk itself).
